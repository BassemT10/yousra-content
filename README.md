# محتوى تطبيق يُسرى
ملفات المحتوى (الأدعية، الزيارات، المناسبات، الأصوات…) التي يجلبها التطبيق، ولوحة التحكم التي تعدّلها.
- `content/` ملفات JSON
- `media/` الصوتيات والصور المرفوعة من لوحة التحكم
- `admin/` لوحة التحكم

## مصادر المحتوى
- نصوص الأدعية والزيارات مأخوذة من [ويكي شيعة](https://ar.wikishia.net) (رخصة CC BY-SA)، وأصلها مفاتيح الجنان.
- التسجيلات الصوتية الأولى من [أرشيف الإنترنت](https://archive.org) وهي معلَّمة فيه بعلامة الملكية العامة: دعاء كميل (mohammed_201505)، دعاء العهد (arkaan99_yahoo)، الزيارة الجامعة (AlzyaraAljame3a_BoHakeem).
- تلاوة القرآن: everyayah.com.
